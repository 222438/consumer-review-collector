# Generation Record

## Scope

This package is a classroom simulation for Bluetooth noise-cancelling earbud competition analysis. Every brand, platform, product, review and interaction count is fictional. It was not scraped from an e-commerce site and has no real-market representativeness.

## Questions

1. In a simulated ANC earbud market, how do the four fictional brands differ in price, rating, review volume and interaction volume?
2. Does a higher simulated price coincide with higher simulated noise-cancellation and usage-experience scores?

## Brand personas

| Brand | Fictional positioning |
|---|---|
| NovaPulse (Xinmai) | Affordable everyday ANC for students and commuters |
| QuietNest (Jingchao) | Premium quiet workspace and travel product |
| AirMorrow (Fengxu) | Lightweight sport and outdoor product |
| BassForge (Dipin Gongfang) | Bass-focused entertainment product |

## Method comparison

| Method | Strength | Limitation | Decision |
|---|---|---|---|
| Ask AI to output a whole table | Fast for a tiny example | Hard to reproduce and control row counts or defect rates | Not selected |
| Use an AI-assisted Python generator | Fixed seed, adjustable rules, repeatable and easy to audit | Requires checking the code and its outputs | Selected |
| Use a teacher-provided dataset | Consistent class-wide input | Not available in the supplied materials and may not match the chosen questions | Not selected |

## Defect injection

The source intentionally includes missing product names, prices, dates and optional counts; duplicate IDs; currency and date format variants; brand aliases and typos; comma and `k` count formats; negative prices/counts; rating 70; rating above 5; noise-cancellation score 70; battery 99 hours; and Chinese numeral text.

## Reproduction

```text
python scripts/generate_data.py
python scripts/clean_data.py
```

The first command refuses to overwrite an existing raw CSV. To test generation safely in another location, pass `--output C:/temp/raw_data.csv`; the sample is written beside that temporary file. The second command reads the raw file, writes the processed CSV and regenerates all QA artifacts.
