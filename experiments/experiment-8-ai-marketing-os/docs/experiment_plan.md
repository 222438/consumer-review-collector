# A/B / 问卷测试方案

## 假设与版本

因为评论中的口味、等待和价格反馈反复出现，我们测试两条只改变传播主题的素材：A 组为“新品上市”，B 组为“先看口味与等待实测，再决定”。目标人群是学生和校园教职工。预注册主指标为购买率，次指标为点击率和开放反馈有效率，护栏指标为负面反馈率与优惠误解反馈。A/B 各至少20人，示例为30/30；真实执行时应在开始前锁定样本量、观察窗口、分组规则和停止规则。

## 事件与字段

| 事件 | 字段 | 定义 |
|---|---|---|
| exposure | `participant_id`, `group`, `channel` | 匿名用户看到素材 |
| click | `clicked` | 点击二维码/详情页 |
| purchase | `purchased` | 在同一观察窗口完成购买 |
| feedback | `open_feedback` | 自由文本，去除姓名、电话、学号 |

组内点击率 = 点击数 / 曝光数；组内购买率 = 购买数 / 曝光数；相对提升 = (B−A)/A。程序从逐行数据计算，避免手工汇总；当前课堂样本不做显著性检验，正式投放需要固定窗口、功效/样本量计算和置信区间。

## 执行、复盘与下一轮

1. 发布前锁定假设、素材唯一变量、样本门槛和护栏指标。
2. 以匿名编号随机分组；保持渠道、时间和优惠规则一致，不提前根据中途结果停测。
3. 测试结束导入 CSV，检查两组样本和重复 ID，再查看主指标、次指标、护栏和开放反馈主题。
4. 如果点击提升但购买不提升，保留 B 组主题并优先优化落地页、优惠解释和承接；如果购买率提升且护栏稳定，扩大到下一批小流量；如果都没有提升，按反馈重写利益点并复测。结论不能只写“哪个更好”。

## 隐私和限制

只收集匿名 ID 和必要行为字段，不把姓名、电话、邮箱或学号写入 CSV/UTM。示例文件是课堂模拟数据，不能证明校园总体偏好；正式报告须补充真实授权、同意、渠道均衡和显著性/不确定性说明。
