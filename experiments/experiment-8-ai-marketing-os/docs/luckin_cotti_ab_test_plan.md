# 瑞幸 vs 库迪广告 A/B 测试方案

> 本方案按 GitHub `coreyhaines31/marketingskills` 的 `ab-testing` 方法整理，并结合本项目的 `skills/ab_testing/SKILL.md` 执行。由于当前没有提供具体广告截图、视频或链接，下面的广告版本是“匹配模板”的测试稿，不评价某一条已发布广告，也不把瑞幸或库迪的当前优惠、口号当成事实数据。

## 先把问题说准确

如果把瑞幸现有广告和库迪现有广告直接各投一组，结果会同时受到品牌、Logo、颜色、文案、产品、价格、优惠、版式、投放渠道和发布时间影响。那可以回答“这两条完整广告哪个表现好”，但不能回答“品牌本身哪个更能促进购买”。

本次主实验采用**匹配模板**：只改变品牌名称/Logo，产品、价格、优惠、版式、CTA、投放渠道和展示时间保持一致。这样把主要变量限定为“品牌标识”，满足一次只测试一个变量的原则。

如果目标是比较两家广告创意，而不是品牌效果，应另开一轮实验：在瑞幸内部比较“价格利益点 vs 口味利益点”，在库迪内部也比较同样的两个版本；不要把品牌变量和创意变量放在同一轮里。

## 假设

因为两家品牌的广告可能让消费者形成不同的购买预期，我们相信在相同产品、价格、版式和 CTA 下，品牌标识的改变会造成未来 7 天购买意愿的差异。我们用购买意愿、广告记忆和信任度判断差异是否值得进入下一轮真实投放。

实验开始前不预设哪一家获胜。方向性假设是：

- `H0`：瑞幸版本与库迪版本的购买意愿相同。
- `H1`：两版本的购买意愿不同。

## 两个测试版本

两张素材使用同一张产品图、同一价格和同一优惠；下面只替换 `[品牌名]` 和对应 Logo。价格、优惠和图片必须在上线前由品牌方提供并记录版本号，不能临时改动。

| 版本 | 只变化的内容 | 示例文案 |
|---|---|---|
| A：瑞幸 | 品牌名、Logo | `[瑞幸 Logo]`\n`一杯咖啡，给今天留一点清醒。`\n`查看门店与优惠` |
| B：库迪 | 品牌名、Logo | `[库迪 Logo]`\n`一杯咖啡，给今天留一点清醒。`\n`查看门店与优惠` |

示例文案是测试占位稿，不是两家官方广告文案。若老师要求比较真实广告，应把两张真实素材保存为 `stimulus_A`、`stimulus_B`，记录来源 URL、下载时间、素材哈希、文案和优惠有效期。

## 样本与随机化

- 人群：过去 30 天购买过咖啡、年满 18 岁、目标城市/校园范围内的消费者。
- 排除：品牌员工、广告制作人员、同一设备重复答卷、测试开始前已经看过两张素材的人。
- 随机：受试者进入问卷后由程序按 1:1 随机分配，只看一个版本；同一匿名 ID 只能进入一组。
- 正式样本：如果基线购买意愿约 30%，希望检测 10 个百分点的绝对提升，双侧 α=0.05、统计功效80%时，约需每组 356 人。正式上线前应根据真实基线重新计算并锁定样本量。
- 课堂演示：每组至少 20 人可以展示流程，但只能称为方向性结果，不能宣称统计显著。

## 指标与观察窗口

| 类型 | 指标 | 计算口径 |
|---|---|---|
| 主指标 | 购买意愿 Top-2 Box | 7分量表中选择 6或7 的人数 / 完成该题人数 |
| 次指标 | 广告记忆率 | 能正确回忆品牌或核心利益点的人数 / 曝光人数 |
| 次指标 | 菜单点击率 | 点击菜单/门店 CTA 的人数 / 曝光人数 |
| 护栏指标 | 信任度、价格公平感、负面反馈率 | 不能因购买意愿提升而明显恶化 |
| 诊断指标 | 开放反馈主题、完成时长、渠道 | 用来解释为什么有效或无效 |

问卷测试使用曝光后即时的购买意愿；如果能接真实门店或小程序，购买转化观察窗口固定为曝光后 7 天。分子和分母必须来自同一时间窗口，不能拿全周期曝光除以部分周期购买。

## 执行流程

1. 预先登记假设、素材版本、主指标、样本量、观察窗口和停止规则。
2. 检查两张素材除品牌标识外完全一致，并给素材生成哈希。
3. 随机分组，记录匿名 `participant_id`、`group`、`exposed_at`、`channel` 和指标事件；不记录姓名、电话、邮箱、学号。
4. 测试期间不根据中途结果提前停测，不更换素材，不混入新的渠道。
5. 测试结束后按行级数据计算两组主指标、绝对差、相对差、95% 置信区间和预先登记的显著性检验。
6. 交叉核对：总曝光数应等于 A 组加 B 组；点击和购买不能大于曝光；匿名 ID 不得重复；每组达到预设样本量。

## 决策规则

- **可进入下一轮**：主指标差异达到预设门槛，置信区间支持方向，护栏指标没有恶化；保留获胜版本并在新渠道复测。
- **结果不确定**：置信区间跨过 0 或样本不足；报告“暂无可靠差异”，不要写成某品牌更好，继续收集或重新设计测试。
- **点击提升但购买不提升**：不要扩大预算；先检查落地页、优惠解释、门店库存和购买承接，再测试第二轮。
- **购买提升但信任度下降**：暂停扩大，先修改夸张或容易误解的表达。

## 数据合规与证据链

受试者需在问卷开头看到用途、匿名化说明和退出方式。数据文件只保留匿名 ID；开放反馈先做个人信息清理。证据包括素材文件、素材哈希、随机分组日志、逐行问卷回答、指标计算脚本和最终分析报告。每个结论必须能回到素材版本和匿名记录。

## AI 与程序的分工

- **程序计算**：随机分组、样本检查、点击率/购买意愿率、绝对差、相对提升、置信区间、重复 ID 和证据引用。
- **AI 辅助**：根据消费者洞察提出广告假设、生成占位文案、归纳开放反馈主题、解释可能原因和提出下一轮方案。
- **人工审核**：确认素材确实只改一个变量、广告主张真实、优惠和品牌合规、样本授权有效。AI 不能替代统计检验或合规审批。

## 本项目中的落地方式

可以把本方案的数据字段映射到 `data/ab_test_anonymous.csv`：`participant_id` 对应匿名 ID，`group` 对应 A/B，`clicked` 对应 CTA 点击，`purchased` 对应购买，`open_feedback` 对应开放反馈。当前示例数据是课堂模拟数据；替换真实数据后，应重新运行 `run.py` 并更新 `outputs/analysis_report.md`。
