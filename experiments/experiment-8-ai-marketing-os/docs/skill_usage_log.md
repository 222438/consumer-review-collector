## 本次实际应用

1. 先识别混淆变量：直接拿两条真实广告比较会同时改变品牌、创意、价格、优惠和投放条件。
2. 按 Skill 的单变量原则设计匹配模板，只改变品牌名/Logo。
3. 按 Skill 的假设框架预注册购买意愿差异，并把广告记忆、点击率作为次指标，把信任度和负面反馈作为护栏指标。
4. 按 Skill 的统计严谨性要求给出样本量计算示例，规定不提前停测，并区分正式测试和课堂方向性演示。
5. 按 Skill 的结果解释规则，为“购买提升”“无可靠差异”“点击提升但购买不提升”“信任度下降”分别规定下一步动作。

## 可复现提示

本方案没有把当前瑞幸或库迪的广告主张写成事实。若使用真实广告，请将截图/视频、来源 URL、下载日期和素材哈希作为输入证据，再按同一测试方案运行。
