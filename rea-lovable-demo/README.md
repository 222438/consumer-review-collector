# REA Demo: Forgeflow

这是“REA 软件逆向工程创业大赛”的可运行 DEMO。项目选取海外 AI 软件构建平台 **Lovable** 作为研究对象，并以公开产品能力为参考，重新设计了一个原创的中文工作台界面 `Forgeflow`。

## 研究对象

- 公司：Lovable（瑞典 / 海外 AI 软件构建平台）
- 产品：通过自然语言描述生成可运行的网站和应用，并支持继续对话式修改
- 融资依据：Lovable 在 2025 年公开宣布完成 2 亿美元融资，估值 18 亿美元。提交时请同时保留官方公告链接作为外部证据：<https://lovable.dev/blog/2025/07/01/lovable-raises-200m>
- 产品参考：<https://lovable.dev/>

## 逆向拆解

本 DEMO 复现的是产品的核心交互闭环，而不是复制原站代码或品牌资产：

1. 工作区侧栏：项目、模板、集成和设置，模拟 AI 建站产品的工作上下文。
2. Prompt 入口：用户输入产品目标，或点击常用场景快速填入提示词。
3. Build 反馈：用前端状态模拟“生成中 / 已准备好”的即时反馈。
4. Recent projects：用项目缩略图和最近编辑时间表达生成结果的持续管理。

## 运行

无需安装依赖，直接用浏览器打开 `index.html` 即可。也可以在本目录执行：

```powershell
python -m http.server 5173
```

然后访问 <http://localhost:5173>。

## 边界说明

这是学习用途的产品交互逆向原型。实现使用原创名称、布局、样式和代码，不接入 Lovable 的私有接口，也不会声称生成真实代码。融资事实和产品能力均以 README 中的公开链接为准。
